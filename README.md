## ⚡ Features & Modules

- **Interactive 808 Phonk Visualizer (`/visualizer`)**:
  - Web Audio API real-time 2048-band FFT DSP engine.
  - Multi-band frequency splitting (Sub-bass 808 distortion pulse, Mid cowbells & vocal chops, Treble transient spark particles).
  - 3 Render Modes: **Radial 808 Ring**, **Cyber Waveform Oscilloscope**, and **3D Drift Grid Road**.
  - Dual Aspect Ratio Switcher: `16:9` (Stage / Desktop) vs `9:16` (Instagram Reels / TikTok screen recording).
  - Multi-source audio: Native DJ Caat masters (`YOi YOi`, `TIMRO YAAD MA`, `NEPAMORPHOSIS`), custom file upload (`.mp3`/`.wav`), and live microphone input.
- **Instagram Bio Hub (`/links`)**:
  - Sub-100ms mobile Linktree replacement optimized for Instagram's in-app browser.
  - Verified artist badge, academic notice card, and 1-tap streaming routes.
- **The Collab Machine (`/collab`)**:
  - Eliminates fragmented Instagram DMs with structured intake for international vocalists and producers.
  - Vocal stem upload, cloud link intake (Google Drive / Dropbox / WeTransfer), subgenre routing, and automated ticket generation (`#CAAT-XXXX`).
- **Producer Sound Vault (`/store`)**:
  - Phonk sound kits (808 Distortion Vault Vol. 1, Himalayan Drift Suite, Memphis Cowbell Kit, FL Studio Mixer Presets).
  - In-card audio preview players, dynamic USD ($) / INR (₹) currency switcher, and simulated instant download checkout.
- **Electronic Press Kit (`/epk`)**:
  - Verified streaming metrics (33.3K+ IG followers, 100K+ streams, top regions: IN, BR, NP, US).
  - Official artist biography highlighting Darjeeling roots and Himalayan / Brazilian phonk fusion.
  - One-click Brand Assets Vault (vector logos and cover art).
  - Direct sync licensing and management inquiry routing.
- **Owner-Protected Plan Portal (`/admin/plan`)**:
  - Restricted management portal gated behind a secure PIN (`7777`) containing the commercial invoice, itemized project budget, domain priority strategy, and zero-upkeep cloud hosting table.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Actions, TypeScript)
- **Styling:** Tailwind CSS (Custom Dark Phonk / Cyberpunk design system)
- **Audio Engine:** HTML5 Web Audio API (`AudioContext`, `AnalyserNode`, 2048 FFT) + HTML5 Canvas
- **Icons:** `lucide-react`
- **Deployment:** Vercel Edge Runtime

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/ripplewave2025/DjCaat.git
cd DjCaat
npm install
```

### 2. Run Locally
```bash
npm run dev
# Open http://localhost:3000 in your browser
```

### 3. Production Build
```bash
npm run build
npm start
```
